=== Subidor de productos ===
Requires at least: 5.5
Tested up to: 6.6
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

Importa productos en borrador desde un paquete ZIP creado con la app Subidor de productos.

== Description ==
Instale el plugin, vaya a Herramientas > Subidor de productos y suba el ZIP que genera la app.
Crea cada producto como borrador con sus fotos (WebP). Funciona con WooCommerce o con cualquier tipo de contenido.
Se puede volver a subir el mismo ZIP sin duplicar: omite los productos que ya existen.
